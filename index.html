☁️ Google Drive Sync

เชื่อมต่อ Google Drive เพื่อ sync ข้อมูลข้ามเครื่องได้ในคลิกเดียว

🔧 ขั้นตอนตั้งค่าครั้งแรก (ทำแค่ครั้งเดียว ~5 นาที)
1. ไปที่ console.cloud.google.com
2. สร้าง Project ใหม่ → ตั้งชื่อ "TPT Planner"
3. ไปที่ APIs & Services → Library → เปิด Google Drive API
4. ไปที่ OAuth consent screen → เลือก External → กรอกชื่อแอป → บันทึก
5. ไปที่ Credentials → Create Credentials → OAuth Client ID
6. Application type: Web application → Authorized origins: file:// และ http://localhost
7. Copy Client ID ที่ได้ → วางในช่องด้านล่าง

💾 จัดการข้อมูล

Backup/Restore แบบ manual หรือ Export CSV

📋 รูปแบบ CSV ที่รองรับ
คอลัมน์ที่ต้องมี: name และ date (รูปแบบ DD-MM)
คอลัมน์ optional: audience, difficulty, priority, keywords, worksheetTypes (คั่นด้วย |), tagsPrimary (คั่นด้วย |), tagsSecondary (คั่นด้วย |), notes, existingProducts, insights
เคล็ดลับ: กด "ดาวน์โหลด Template CSV" เพื่อได้ไฟล์ที่กรอกได้เลยค่ะ
